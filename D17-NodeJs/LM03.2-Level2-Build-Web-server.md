
# Level 2 — Implement Manual Routing

Now the server needs different responses depending on the URL.

We will create:

```text
GET /
GET /students
Anything else → 404
```

---

## Step 1 — Create the Home Route

```javascript
if (
    req.url === '/' &&
    req.method === 'GET'
) {
    res.writeHead(200, {
        'Content-Type': 'text/plain'
    });

    res.end(
        'Welcome to the Student Portal API'
    );

    return;
}
```

---

## Step 2 — Add the 404 Route

After the previous block:

```javascript
res.writeHead(404, {
    'Content-Type': 'text/plain'
});

res.end('Not Found');
```

Test:

```bash
curl http://localhost:3000/abc
```

Expected:

```text
Not Found
```

# Level 2.1 — Add `/students`

Create a student array:

```javascript
const students = [
    {
        id: 1,
        name: 'Aditi',
        course: 'Java'
    },
    {
        id: 2,
        name: 'Rahul',
        course: 'Node.js'
    },
    {
        id: 3,
        name: 'Priya',
        course: 'Spring Boot'
    }
];
```

Add the route:

```javascript
if (
    req.url === '/students' &&
    req.method === 'GET'
) {
    res.writeHead(200, {
        'Content-Type': 'application/json'
    });

    res.end(
        JSON.stringify(students)
    );

    return;
}
```

# Level 2 Challenge — HTTP Methods

Try:

```bash
curl -X POST http://localhost:3000/students
```

Currently the request will return:

```text
Not Found
```

Why?

Because we only implemented:

```text
GET /students
```

This demonstrates why both are important:

```javascript
req.method
req.url
```
