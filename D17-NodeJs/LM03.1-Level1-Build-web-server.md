# Hour 3 Progressive Lab — Student Portal HTTP Server & Unit Testing

This lab should continue the **Student File Processing System** from Hour 2, but move it toward a real backend application.

The progression is:

```text
Level 1
Build HTTP Server
      ↓
Level 2
Add Manual Routing
      ↓
Level 3
Build Student API
      ↓
Level 4
Extract Business Logic
      ↓
Level 5
Add Mocha Unit Tests
      ↓
Level 6
Add Hooks + Edge Cases
```

**Recommended duration:** 60–90 minutes
**Difficulty:** Beginner → Intermediate
**Technology:** Node.js, built-in `http`, Mocha, Node `assert`

---

# Lab Scenario

## Student Portal API

You are developing a backend for a training institute.

The system already has student information from the previous lab.

Now management wants a simple HTTP API:

```text
                    Student Portal
                         |
                Node.js HTTP Server
                         |
          +--------------+--------------+
          |              |              |
          ↓              ↓              ↓
        GET /      GET /students    GET /students/:id
          |              |              |
          ↓              ↓              ↓
      Welcome        All Students    One Student
```

The application must eventually support:

```text
GET /
GET /students
GET /students/1
GET /students/999
```

And return appropriate HTTP status codes.

After the API is working, students will extract reusable business logic and write **unit tests using Mocha**.

# Level 1 — Create the HTTP Server

## Objective

Understand how Node.js receives an HTTP request and sends an HTTP response.

---

## Step 1 — Create the project

```bash
mkdir student-portal-api
cd student-portal-api
```

Initialize Node.js:

```bash
npm init -y
```

Create:

```bash
touch server.js
```

Your structure:

```text
student-portal-api/
├── package.json
└── server.js
```

---

## Step 2 — Import the HTTP module

Open `server.js`:

```javascript
const http = require('http');
```

---

## Step 3 — Create the server

Add:

```javascript
const server = http.createServer((req, res) => {
    console.log('Request received');
});
```

The callback:

```javascript
(req, res) => {}
```

is executed whenever a request reaches the server.

---

## Step 4 — Start the server

Add:

```javascript
server.listen(3000, () => {
    console.log(
        'Server running on http://localhost:3000'
    );
});
```

Complete program:

```javascript
const http = require('http');

const server = http.createServer((req, res) => {
    console.log('Request received');
});

server.listen(3000, () => {
    console.log(
        'Server running on http://localhost:3000'
    );
});
```

Run:

```bash
node server.js
```

Expected:

```text
Server running on http://localhost:3000
```

# Level 1.1 — Inspect the Request

Modify the request handler:

```javascript
const server = http.createServer((req, res) => {

    console.log('Method:', req.method);
    console.log('URL:', req.url);

});
```

Open:

```text
http://localhost:3000
```

Look at the terminal.

You should see:

```text
Method: GET
URL: /
```

Try:

```text
http://localhost:3000/students
```

You should see:

```text
Method: GET
URL: /students
```

# Level 1.2 — Send a Response

Modify the handler:

```javascript
const server = http.createServer((req, res) => {

    res.writeHead(200, {
        'Content-Type': 'text/plain'
    });

    res.end(
        'Welcome to Student Portal'
    );
});
```

Run:

```bash
node server.js
```

Open:

```text
http://localhost:3000
```

Expected:

```text
Welcome to Student Portal
```
