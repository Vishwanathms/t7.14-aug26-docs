# Level 5 — Introduce Mocha

Now we add automated unit testing.

---

## Step 1 — Install Mocha

Run:

```bash
npm install --save-dev mocha
```

Verify:

```bash
npm list mocha
```

---

# Level 5.1 — Configure npm Test

Open `package.json`.

Add:

```json
{
    "scripts": {
        "test": "mocha"
    }
}
```

Your scripts section should look like:

```json
"scripts": {
    "test": "mocha"
}
```

---

# Level 5.3 — First Unit Test

Open:

```text
test/student-service.test.js
```

Add:

```javascript
const assert =
    require('assert');

const {
    getAllStudents
} = require('../student-service');

describe(
    'Student Service',
    () => {

        it(
            'should return all students',
            () => {

                const students =
                    getAllStudents();

                assert.strictEqual(
                    students.length,
                    3
                );
            }
        );

    }
);
```

Run:

```bash
npm test
```

Expected:

```text
✔ should return all students

1 passing
```

# Level 5.6 — Understand `describe()` and `it()`

Our test structure:

```text
describe()
    |
    +-- it()
    |
    +-- it()
    |
    +-- it()
```

Think:

```text
describe()
    =
Test Suite

it()
    =
Test Case
```

For example:

```javascript
describe(
    'Student Service',
    () => {
        // student service tests
    }
);
```

And:

```javascript
it(
    'should return student with ID 1',
    () => {
        // assertion
    }
);
```
