# LAB 6 — Create RestClient

## Objective

Use Spring Boot `RestClient` to call the Course Service.

---

# Step 1. Understand the Requirement

Currently:

```text
GET /students/101
```

returns:

```json
{
  "id": 101,
  "name": "Rahul",
  "courseId": 10
}
```

We want Student Service to ask:

```text
Course Service:

GET /courses/10
```

Then receive:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

---

# Step 2. Add RestClient

Modify `StudentController`.

Add:

```java
private final RestClient restClient;

public StudentController() {
    this.restClient = RestClient.create();
}
```

Your controller should now contain:

```java
@RestController
@RequestMapping("/students")
public class StudentController {

    private final RestClient restClient;

    public StudentController() {
        this.restClient = RestClient.create();
    }

    // existing endpoint
}
```

---

# Step 3. Add the Import

At the top:

```java
import org.springframework.web.client.RestClient;
```

---

# LAB 7 — Make the First Service-to-Service Call

Now modify the student endpoint.

Replace the method with:

```java
@GetMapping("/{id}")
public Map<String, Object> getStudent(@PathVariable int id) {

    Map<String, Object> student = new HashMap<>();

    student.put("studentId", id);
    student.put("studentName", "Rahul");

    Course course = restClient
            .get()
            .uri("http://localhost:8081/courses/10")
            .retrieve()
            .body(Course.class);

    student.put("course", course);

    return student;
}
```

---

# Step 1. Save Everything

Make sure:

```text
Course Service → RUNNING
Student Service → RUNNING
```

You need both services running.

# LAB 8 — Understand What Just Happened

This is an important checkpoint.

You called:

```text
GET http://localhost:8080/students/101
```

The browser sent the request to:

```text
Student Service
```

The Student Service executed:

```java
restClient
    .get()
    .uri("http://localhost:8081/courses/10")
    .retrieve()
    .body(Course.class);
```

This caused another HTTP request:

```text
Student Service
      |
      | GET /courses/10
      ↓
Course Service
```

Course Service returned:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

Spring converted it into:

```text
Course object
```

The Student Service then included it in its response.

---

# Complete Request Flow

```text
Browser
   |
   | GET /students/101
   ↓
Student Service :8080
   |
   | RestClient
   |
   | GET /courses/10
   ↓
Course Service :8081
   |
   | JSON
   ↓
Student Service
   |
   | JSON
   ↓
Browser
```

# LAB 9 — Make the Course ID Dynamic

## Objective

Currently the Student Service always calls:

```text
/courses/10
```

That is not ideal.

The student has a:

```text
courseId
```

We should use it.

---

# Step 1. Create a Course ID Variable

Modify:

```java
int courseId = 10;
```

Then use:

```java
Course course = restClient
        .get()
        .uri("http://localhost:8081/courses/" + courseId)
        .retrieve()
        .body(Course.class);
```

The important idea is:

```text
Student
  |
  | courseId = 10
  ↓
RestClient
  |
  ↓
/courses/10
```

---

# LAB 10 — Observe Synchronous Communication

The communication we implemented is **synchronous**.

Why?

Because the Student Service waits for:

```text
Course Service
```

to respond.

The flow is:

```text
Student Service
      |
      | Request
      ↓
Course Service
      |
      | Response
      ↓
Student Service
```

Only after receiving the response does Student Service continue.
