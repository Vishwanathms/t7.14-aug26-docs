# Level 6 — Mocha Hooks

Now we introduce:

```text
before()
after()
beforeEach()
afterEach()
```

---

# Level 6.1 — `beforeEach()`

Add:

```javascript
beforeEach(() => {
    console.log(
        'Running before each test'
    );
});
```

Run:

```bash
npm test
```

Observe that it executes before every test.

Conceptually:

```text
beforeEach
    ↓
Test 1
    ↓
beforeEach
    ↓
Test 2
    ↓
beforeEach
    ↓
Test 3
```

---

# Level 6.2 — `afterEach()`

Add:

```javascript
afterEach(() => {
    console.log(
        'Test completed'
    );
});
```

Flow:

```text
beforeEach
    ↓
Test
    ↓
afterEach
```

This becomes useful when tests need cleanup.

---

# Level 6.3 — `before()` and `after()`

Add:

```javascript
before(() => {
    console.log(
        'Starting Student Service tests'
    );
});

after(() => {
    console.log(
        'Student Service tests completed'
    );
});
```

Execution model:

```text
before
  ↓
beforeEach
  ↓
Test
  ↓
afterEach
  ↓
beforeEach
  ↓
Test
  ↓
afterEach
  ↓
after
```

# Level 6.4 — Add More Tests

Create a complete test suite:

```javascript
const assert =
    require('assert');

const {
    getAllStudents,
    getStudentById
} = require('../student-service');

describe(
    'Student Service',
    () => {

        before(() => {
            console.log(
                'Starting tests'
            );
        });

        beforeEach(() => {
            console.log(
                'Preparing test'
            );
        });

        afterEach(() => {
            console.log(
                'Cleaning up'
            );
        });

        after(() => {
            console.log(
                'Tests completed'
            );
        });

        it(
            'should return all students',
            () => {

                const students =
                    getAllStudents();

                assert.strictEqual(
                    students.length,
                    3
                );
            }
        );

        it(
            'should return Aditi for ID 1',
            () => {

                const student =
                    getStudentById(1);

                assert.strictEqual(
                    student.name,
                    'Aditi'
                );
            }
        );

        it(
            'should return Rahul for ID 2',
            () => {

                const student =
                    getStudentById(2);

                assert.strictEqual(
                    student.name,
                    'Rahul'
                );
            }
        );

        it(
            'should return undefined for unknown ID',
            () => {

                const student =
                    getStudentById(999);

                assert.strictEqual(
                    student,
                    undefined
                );
            }
        );
    }
);
```

Run:

```bash
npm test
```

# Level 6.5 — Intentionally Break a Test

Change:

```javascript
assert.strictEqual(
    student.name,
    'Aditi'
);
```

to:

```javascript
assert.strictEqual(
    student.name,
    'Rahul'
);
```

Run:

```bash
npm test
```

Mocha should report a failure.

This is important for students to observe.

```text
Test
 ↓
Expected: Rahul
Actual: Aditi
 ↓
FAIL
```

Fix the test and run again.

```text
PASS
```
