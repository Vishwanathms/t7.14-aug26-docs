
# Level 3 — Student Lookup API

Now management wants:

```text
GET /students/1
```

to return one student.

Expected:

```json
{
    "id": 1,
    "name": "Aditi",
    "course": "Java"
}
```

And:

```text
GET /students/999
```

should return:

```text
Student not found
```

with:

```text
404
```

---

# Level 3.1 — Extract the Student ID

A URL such as:

```text
/students/2
```

contains:

```text
students
   /
  2
```

We can split the URL:

```javascript
const parts = req.url.split('/');
```

For:

```text
/students/2
```

the result is conceptually:

```text
[
    '',
    'students',
    '2'
]
```

Therefore:

```javascript
const studentId = Number(parts[2]);
```

---

# Level 3.2 — Implement the Route

Add:

```javascript
if (
    req.method === 'GET' &&
    req.url.startsWith('/students/')
) {
    const parts = req.url.split('/');
    const studentId = Number(parts[2]);

    const student = students.find(
        student => student.id === studentId
    );

    if (!student) {
        res.writeHead(404, {
            'Content-Type': 'text/plain'
        });

        res.end('Student not found');

        return;
    }

    res.writeHead(200, {
        'Content-Type': 'application/json'
    });

    res.end(
        JSON.stringify(student)
    );

    return;
}
```
