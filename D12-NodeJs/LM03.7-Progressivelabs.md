# Instructor Debrief

The most important concepts to reinforce are **not the syntax**.

### 1. Node HTTP is event-driven

```text
Client Request
      ↓
http Server
      ↓
Request Event
      ↓
Handler
      ↓
Response
```

This connects directly back to **Hour 1's Event Loop and Hour 2's EventEmitter**.

### 2. Frameworks hide complexity

Students should understand why this:

```javascript
if (req.url === '/students')
```

eventually becomes:

```javascript
app.get('/students', handler)
```

in Express.

### 3. Separate business logic from HTTP

This is the most important architectural lesson in the lab:

```text
HTTP Layer
     ↓
Business Layer
```

rather than putting everything inside:

```javascript
http.createServer(...)
```

### 4. Unit tests should test logic independently

Instead of starting the server to test:

```javascript
getStudentById(1)
```

we test the function directly:

```text
Function
   ↓
Input
   ↓
Expected Output
   ↓
PASS / FAIL
```

That concept will transfer directly into **Spring Boot service-layer testing** later.

### Suggested final question to the class

> **If Express and Spring Boot can make web development easier, why did we first build the server using Node's raw `http` module?**

Expected answer:

> **To understand what the framework is actually doing underneath—receiving HTTP requests, routing them, executing application logic, and generating responses.**
