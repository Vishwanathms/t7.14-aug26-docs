Since the entire course is progressing toward **Spring Framework, Docker, MySQL, and later Microservices**, I would actually **containerize the labs from Day 1**. This keeps the student laptops clean (only Docker Desktop + VS Code + Git Bash + JDK installed) and introduces a workflow they'll continue using.

I recommend **2 Docker-based lab manuals** instead of plain Java programs.

---

# Lab Manual 1

# Java Employee Manager in Docker

**Duration:** 3.5 Hours

## Learning Objectives

Students will learn

* Exception Handling
* Collections
* File Handling
* Dockerizing a Java application
* Persisting data using Docker Volumes

---

# Architecture

```
+----------------------------+
|      Docker Container      |
|                            |
|  Java Employee Manager     |
|                            |
|  employees.txt             |
+-------------+--------------+
              |
      Docker Volume
              |
       Host Machine
```

This introduces an important production concept: **containers are ephemeral; volumes provide persistent storage**.

## Lab 5 – Docker Volume

Now explain

Container deleted

↓

Data lost

Fix

```
docker volume create employee-data
```

Run

```bash
docker run \
-v employee-data:/data \
employee-app
```

Save

```
/data/employees.txt
```

Stop container

Delete container

Run again

Verify data still exists.

Students understand

* Persistent storage
* Volumes
