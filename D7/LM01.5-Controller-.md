# Lab 4 — Introduce Controller → Service → Repository

## Objective

Move application logic out of the controller.

---

```text
controller

dto
```

```text
com.example.stumgmt

├── controller

└── dto
```

---

# Step 2 — Create StudentService

```java
@Service
public class StudentService {

    public List<Student> getStudents() {

        List<Student> students = new ArrayList<>();

        students.add(
            new Student(
                101L,
                "Rahul",
                "rahul@example.com",
                "Spring Boot"
            )
        );

        return students;
    }
}
```

---

# Step 3 — Inject Service into Controller

```java
@RestController
public class StudentController {

    private final StudentService studentService;

    public StudentController(StudentService studentService) {
        this.studentService = studentService;
    }

    @GetMapping("/students")
    public List<Student> getStudents() {

        return studentService.getStudents();
    }
}
```

---

# Step 4 — Understand Dependency Injection

Spring creates:

```text
StudentService
```

and provides it to:

```text
StudentController
```

Conceptually:

```text
Spring Container
      |
      ↓
StudentService
      |
      ↓
StudentController
```

---

# Step 5 — Introduce Repository

Create:

```text
StudentRepository
```

```java
public interface StudentRepository

```

# Step 6 — Understand the Final Flow

```text
HTTP Request
     ↓
Controller
     ↓
Service
     ↓
Repository
     ↓
PostgreSQL
```

Response:

```text
PostgreSQL
     ↓
Repository
     ↓
Service
     ↓
Controller
     ↓
JSON Response
```

---

# Step 7 — Refactor

Move all business logic from the controller into the service.

Controller:

```java
@GetMapping("/students")
public List<Student> getStudents() {

    return studentService.getStudents();
}
```

Service:

```java
public List<Student> getStudents() {

    return studentRepository.findAll();
}
```

Repository:

```java
studentRepository.findAll();
```

# Lab 4 Checkpoint

Ask yourself:

### Controller

> What is my HTTP request?

### Service

> What is my business logic?

### Repository

> How do I access the database?

If these responsibilities are mixed together, refactor the application.
