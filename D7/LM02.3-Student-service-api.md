# LAB 3 — Create the Student Service

## Objective

Create another independent Spring Boot application.

This will become the service that consumes the Course Service.

---

# Step 1. Create a New Spring Boot Project

In IntelliJ:

```text
File
 → New
 → Project
```

Select:

```text
Spring Boot
```

Use:

| Setting      | Value             |
| ------------ | ----------------- |
| Name         | `student-service` |
| Language     | Java              |
| Build System | Maven             |
| Packaging    | Jar               |

Dependency:

```text
Spring Web
```

Create the project.

---

# Step 2. Configure Port 8080

Open:

```text
src/main/resources/application.properties
```

Add:

```properties
server.port=8080
```

Why?

Because the Course Service is already using:

```text
8081
```

Two applications cannot normally listen on the same port.

Therefore:

```text
Student Service → 8080
Course Service  → 8081
```

---

# LAB 4 — Create Student REST API

## Objective

First make the Student Service work independently.

---

# Step 1. Create StudentController

Create:

```text
StudentController
```

Add:

```java
package com.example.studentservice;

import org.springframework.web.bind.annotation.*;

import java.util.HashMap;
import java.util.Map;

@RestController
@RequestMapping("/students")
public class StudentController {

    @GetMapping("/{id}")
    public Map<String, Object> getStudent(@PathVariable int id) {

        Map<String, Object> student = new HashMap<>();

        student.put("id", id);
        student.put("name", "Rahul");
        student.put("courseId", 10);

        return student;
    }
}
```

Again, keep your project's actual package name.

---

# Step 2. Run Student Service

Run:

```text
StudentServiceApplication
```

You should see:

```text
Tomcat started on port 8080
```

---

# Step 3. Test Student Service

Open:

```text
http://localhost:8080/students/101
```

Expected response:

```json
{
  "id": 101,
  "name": "Rahul",
  "courseId": 10
}
```

# LAB 5 — Create the Course Java Model

## Objective

The Course Service returns JSON.

The Student Service needs a Java object to represent that JSON.

---

# Step 1. Create Course Class

Inside Student Service, create:

```text
Course.java
```

Add:

```java
public class Course {

    private int id;
    private String name;
    private int duration;

    public int getId() {
        return id;
    }

    public void setId(int id) {
        this.id = id;
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        this.name = name;
    }

    public int getDuration() {
        return duration;
    }

    public void setDuration(int duration) {
        this.duration = duration;
    }
}
```

---

# Why do we need this class?

Course Service sends:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

Student Service can convert this JSON into:

```text
Course object
```

Conceptually:

```text
JSON
 ↓
Course.class
 ↓
Java Object
```

Spring Boot/Jackson handles the conversion.
