# Lab 1 — Create the First REST API

## Objective

Create your first REST endpoint:

```http
GET /students
```

The endpoint should return student information as JSON.

---

# Step 1 — Open the Project

Open your existing Student Management project in IntelliJ IDEA.

The project should have a structure similar to:

```text
src
 └── main
      └── java
           └── com.example.stumgmt
                └── StumgmtApplication.java
```

---

# Step 2 — Create the Controller Package

Inside your main Java package, create:

```text
controller
```

Example:

```text
com.example.stumgmt
├── controller
└── StumgmtApplication.java
```

---

# Step 3 — Create StudentController

Create:

```text
StudentController.java
```

Add:

```java
package com.example.stumgmt.controller;

import org.springframework.web.bind.annotation.GetMapping;
import org.springframework.web.bind.annotation.RestController;

@RestController
public class StudentController {

    @GetMapping("/students")
    public String getStudents() {
        return "Student Management System";
    }
}
```

---

# Step 4 — Understand the Annotations

## @RestController

```java
@RestController
```

Tells Spring:

> This class contains REST API endpoints.

---

## @GetMapping

```java
@GetMapping("/students")
```

Means:

> When a client sends a GET request to `/students`, execute this method.

---

Run:

StumgmtApplication

```

http://localhost:8080/students
```

```text
Student Management System
```

---

# Step 7 — Return JSON

Now replace:

```java
return "Student Management System";
```

with:

```java
Map<String, Object> student = new HashMap<>();

student.put("id", 101);
student.put("name", "Rahul");
student.put("course", "Spring Boot");

return student;
```

Add imports:

```java
import java.util.HashMap;
import java.util.Map;
```

The complete method:

```java
@GetMapping("/students")
public Map<String, Object> getStudents() {

    Map<String, Object> student = new HashMap<>();

    student.put("id", 101);
    student.put("name", "Rahul");
    student.put("course", "Spring Boot");

    return student;
}
```

---

# Step 8 — Test Again

Open:

```text
http://localhost:8080/students
```

Expected:

```json
{
  "id": 101,
  "name": "Rahul",
  "course": "Spring Boot"
}
```

Spring Boot automatically converts the Java `Map` into JSON.
