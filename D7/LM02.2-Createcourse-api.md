# LAB 1 — Create the Course Service

## Objective

Create a Spring Boot application that provides course information through a REST API.

---

## Step 1. Open IntelliJ IDEA

Open IntelliJ IDEA.

Select:

```text
New Project
```

Select:

```text
Spring Boot
```

---

## Step 2. Configure the Project

Use the following values.

| Setting      | Value              |
| ------------ | ------------------ |
| Name         | `course-service`   |
| Language     | Java               |
| Build System | Maven              |
| JDK          | Your installed JDK |
| Packaging    | Jar                |

Add dependency:

```text
Spring Web
```

Create the project.

---

# Step 3. Wait for Maven

After the project opens, wait for IntelliJ to finish downloading dependencies.

You should see Maven dependencies being resolved.

If necessary:

```text
Maven
   ↓
Reload All Maven Projects
```

---

# Step 4. Locate the Main Class

You will have a class similar to:

```java
CourseServiceApplication
```

Do not modify it yet.

---

# Step 5. Create the Controller

Navigate to:

```text
src
 └── main
     └── java
         └── <your package>
```

Right-click the package.

Select:

```text
New
 → Java Class
```

Name it:

```text
CourseController
```

---

# Step 6. Add the Controller Code

Replace the contents with:

```java
package com.example.courseservice;

import org.springframework.web.bind.annotation.*;

import java.util.HashMap;
import java.util.Map;

@RestController
@RequestMapping("/courses")
public class CourseController {

    @GetMapping("/{id}")
    public Map<String, Object> getCourse(@PathVariable int id) {

        Map<String, Object> course = new HashMap<>();

        course.put("id", id);
        course.put("name", "Spring Boot");
        course.put("duration", 40);

        return course;
    }
}
```

> **Important:** If your package name is different, keep your existing package name.

---

# Step 7. Understand the Code

The following annotation:

```java
@RestController
```

tells Spring Boot that this class handles REST requests.

This:

```java
@RequestMapping("/courses")
```

defines the base URL.

This:

```java
@GetMapping("/{id}")
```

handles a GET request such as:

```text
/courses/10
```

This:

```java
@PathVariable int id
```

extracts:

```text
10
```

from the URL.

---

# Step 8. Configure the Port

Open:

```text
src/main/resources/application.properties
```

Add:

```properties
server.port=8081
```

Save the file.

---

# Step 9. Run Course Service

Open:

```text
CourseServiceApplication
```

Click:

```text
Run
```

You should see something similar to:

```text
Tomcat started on port 8081
Started CourseServiceApplication
```

---

# Checkpoint 1

The Course Service should now be running on:

```text
http://localhost:8081
```

---

# LAB 2 — Test the Course REST API

## Objective

Verify that the Course Service works independently before another service consumes it.

---

## Step 1. Open the Browser

Open:

```text
http://localhost:8081/courses/10
```

---

## Expected Result

You should receive JSON similar to:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

The exact ordering of JSON fields may differ.

That is normal.

---

# Step 2. Try Another Course ID

Change:

```text
/courses/10
```

to:

```text
/courses/20
```

You should get:

```json
{
  "id": 20,
  "name": "Spring Boot",
  "duration": 40
}
```

Notice:

```text
10 → id = 10
20 → id = 20
```

The ID is coming from the URL.

---

# Checkpoint 2

At this point:

```text
Browser
   |
   | GET /courses/10
   ↓
Course Service :8081
   |
   ↓
JSON Response
```

The Course Service works correctly.
