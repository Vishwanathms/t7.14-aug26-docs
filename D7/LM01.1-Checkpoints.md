Below is a **progressive student lab manual** covering **Hands-on Lab 1 through the final assignment**. It assumes students are continuing with the **existing Spring Boot Student Management project in IntelliJ**, rather than creating a new project for every lab.

# Student Management REST API

## Progressive Hands-On Lab Manual

### Technology Stack

* Java 17+
* Spring Boot
* Maven
* IntelliJ IDEA
* PostgreSQL
* Spring Data JPA
* REST APIs
* JSON
* Postman
* Bean Validation

---

# 1. Lab Overview

## Objective

In this series of labs, you will progressively build a REST API for a Student Management System.

You will start with a simple:

```text
GET /students
```

and gradually build a more realistic API supporting:

```text
CRUD
+
DTOs
+
Validation
+
Error Handling
+
Layered Architecture
+
Pagination
+
Filtering
+
Sorting
```

By the end, your application should look like:

```text
                    Client
               Browser / Postman
                       |
                       | HTTP
                       ↓
              ┌─────────────────┐
              │   Controller    │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │     Service     │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │   Repository    │
              └────────┬────────┘
                       ↓
              ┌─────────────────┐
              │   PostgreSQL    │
              └─────────────────┘
```

# 3. Prerequisites

Before starting, make sure the following are available.

## Verify Java

Open a terminal:

```bash
java -version
```

Expected:

```text
java version "17..."
```

or a newer supported version.

---

## Verify Maven

```bash
mvn -version
```

---

## Verify PostgreSQL

If PostgreSQL is running locally:

```bash
psql --version
```

If PostgreSQL is running through Docker:

```bash
docker ps
```

---

## Verify the Spring Boot Application

Open the existing project in IntelliJ.

Run:

```text
StudentManagementApplication
```

The application should start successfully.
