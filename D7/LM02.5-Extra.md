# LAB 11 — Introduce Failure

## Objective

Understand what happens when a downstream service is unavailable.

This is one of the most important exercises.

---

# Step 1. Keep Student Service Running

Do not stop:

```text
Student Service :8080
```

---

# Step 2. Stop Course Service

Stop the Course Service from IntelliJ.

Now:

```text
Student Service → RUNNING

Course Service → STOPPED
```

---

# Step 3. Call Student Service

Open:

```text
http://localhost:8080/students/101
```

---

# Step 4. Observe the Result

The Student Service tries:

```text
GET http://localhost:8081/courses/10
```

But nothing is listening on port `8081`.

Therefore, the request fails.

You may see an exception/error response depending on your Spring Boot version and configuration.

---

# Understand the Failure

```text
Browser
   |
   | GET /students/101
   ↓
Student Service
   |
   | GET /courses/10
   ↓
Course Service
      X
    DOWN
```

The important observation is:

> Student Service itself did not necessarily have a problem. Its dependency had a problem.

---

# LAB 12 — Restart the Course Service

Start:

```text
CourseServiceApplication
```

Wait for:

```text
Tomcat started on port 8081
```

Then test again:

```text
http://localhost:8080/students/101
```

The request should work again.

# LAB 13 — Challenge Exercise

Now modify the Course Service to support multiple courses.

For example:

```text
10 → Spring Boot
20 → Docker
30 → Kubernetes
```

Modify the controller so that:

```text
GET /courses/10
```

returns:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

and:

```text
GET /courses/20
```

returns:

```json
{
  "id": 20,
  "name": "Docker",
  "duration": 20
}
```

and:

```text
GET /courses/30
```

returns:

```json
{
  "id": 30,
  "name": "Kubernetes",
  "duration": 30
}
```

Then modify Student Service to request different course IDs.

# LAB 14 — Final Verification

At the end, verify the following.

## Course Service

```text
http://localhost:8081/courses/10
```

Expected:

```json
{
  "id": 10,
  "name": "Spring Boot",
  "duration": 40
}
```

---

## Student Service

```text
http://localhost:8080/students/101
```

Expected:

```json
{
  "studentId": 101,
  "studentName": "Rahul",
  "course": {
    "id": 10,
    "name": "Spring Boot",
    "duration": 40
  }
}
```
