# Progressive Lab Manual — Student Profile Portal

**Level:** Fresher
**Duration:** 30–40 minutes
**Prerequisite:** Basic JavaScript functions and HTML
**Goal:** Understand **Components → JSX → Props → `children` → Default Props**

---

By the end of this lab, students will build:

```text

├── Header
```

# Step 1 — Create the React Project

Open a terminal.

Create the project using Vite:

```bash
npm create vite@latest student-profile-portal
```

When prompted:

```text
Framework: React
Variant: JavaScript
```

Move into the project:

```bash
cd student-profile-portal
```

Install dependencies:

```bash
npm install
```

Start the application:

```bash
npm run dev
```

You should see something similar to:

```text
Local: http://localhost:5173/
```

Open that URL in the browser.

# Step 10 — Add Default Prop Value

Now remove the `year` from Priya:

```jsx
<StudentCard
  name="Priya"
  department="Information Science"
  email="priya@example.com"
/>
```

If we leave our component as:

```jsx
function StudentCard({ name, department, year, email }) {
```

the year will be empty.

Instead, use a default value:

```jsx
function StudentCard({
  name,
  department,
  year = 1,
  email
}) {
```

Now Priya automatically gets:

```text
Year: 1
```

### Important concept

```text
year provided
     ↓
use provided value

year NOT provided
     ↓
use 1
```

# Step 12 — Understand `children`

Explain what happens here:

```jsx
<Card>
  <h2>Aditi</h2>
  <p>Computer Science</p>
</Card>
```

Everything between:

```jsx
<Card>
```

and:

```jsx
</Card>
```

becomes:

```jsx
children
```

Inside `Card`:

```jsx
function Card({ children }) {
  return (
    <div className="card">
      {children}
    </div>
  );
}
```

Think of it as:

```text
<Card>
   CONTENT
</Card>
   │
   ↓
children
```

# Step 20 — Fresher Checkpoint

Before completing the lab, ask students to answer these questions.

### 1. What is a component?

A reusable UI building block.

### 2. How do we create a function component?

```jsx
function StudentCard() {
  return <div>Student</div>;
}
```

### 3. How does the parent send data to the child?

Using **props**.

```jsx
<StudentCard name="Aditi" />
```

### 4. How does the child receive the prop?

```jsx
function StudentCard({ name }) {
```

### 5. Are props mutable?

No. Props should be treated as read-only.

### 6. What is `children`?

The content placed between a component's opening and closing tags.

### 7. What happens if `year` isn't provided?

Our default value is used:

```jsx
year = 1
```

### Success Criteria

Students have successfully completed the lab when they can independently demonstrate:

```text
1. Create a component
       ↓
2. Import the component
       ↓
3. Use the component
       ↓
4. Pass props
       ↓
5. Receive props
       ↓
6. Use children
       ↓
7. Set default prop values
       ↓
8. Compose multiple components
```

This gives freshers a **progressive path from a blank Vite project to a small component-based React application**, without introducing state, hooks, APIs, or routing yet.
